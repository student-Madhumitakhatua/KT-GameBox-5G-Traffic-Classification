KT GAMEBOX 5G TRAFFIC CLASSIFICATION USING MACHINE LEARNING
===============================================================

PROJECT OBJECTIVE
-----------------
The objective of this project is to classify network packets from the KT GameBox 5G traffic dataset into two protocol classes: TCP and UDP. Ten CSV files were merged, analyzed, cleaned, balanced, preprocessed, and used for Machine Learning model training and comparison.

Missing values = 0

6. REMOVING UNNECESSARY / LEAKAGE-PRONE COLUMNS
------------------------------------------------
The following columns were removed:

No.
Info

Reason for removing No.:
No. is only a packet sequence/identifier and does not represent useful network traffic characteristics.

Reason for removing Info:
Info contains packet descriptions such as SYN, ACK, Client Hello, and Application Data. These descriptions can directly expose protocol-related information and could create target leakage.

Remaining columns:

Time
Source
Destination
Protocol
Length


7. TIME PREPROCESSING AND LEAKAGE CHECK
----------------------------------------
Time was converted into datetime format.

Initially, these time features were created:

hour
minute
second

Further analysis showed that time was strongly associated with the protocol. For example:

Hour 15 -> 100% TCP
Hour 16 -> 100% TCP
Hour 17 -> 100% TCP

Therefore, hour, minute, and second were removed from the final model to reduce temporal leakage.

10. CATEGORICAL ENCODING
------------------------
Source and Destination are categorical IP-address features.

One-Hot Encoding was used instead of treating IP addresses as ordered numerical values.

8 unique Destination values

8 Destination features

The encoder was fitted only on training data and then applied to test data to avoid train-test leakage.

18. IMPORTANT LIMITATION
------------------------
The 99.99% performance should be interpreted carefully.

During analysis, Source and Destination were found to be highly associated with the protocol. Several IP addresses were associated almost exclusively with TCP traffic.

Therefore, the reported 99.99% represents performance on the prepared held-out test set. It should not automatically be interpreted as 99.99% generalization to completely unseen network environments.

A stronger future evaluation would use session-aware or environment-aware train/test splitting and more general flow-level network traffic features.

20. FINAL CONCLUSION
--------------------
This project demonstrates an end-to-end Machine Learning workflow for TCP and UDP traffic classification using KT GameBox 5G traffic data.

The process included:

- Merging 10 large CSV files
- Analyzing protocol distribution
- Creating a balanced TCP/UDP dataset
- Data cleaning
- Removing unnecessary and leakage-prone columns
- Time preprocessing and leakage detection
- One-Hot Encoding
- Stratified train-test splitting
- Standard feature scaling
- ANOVA-based feature selection
- Training multiple Machine Learning models
- Comparing model performance
- Evaluating the best model using a confusion matrix

Final comparison:

Logistic Regression -> 92.77%
Linear SVM          -> 92.76%
Decision Tree       -> 99.99%
Random Forest       -> 99.99%

Decision Tree was selected as the final model for this experimental setup.
